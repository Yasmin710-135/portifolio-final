Calculadora de IMC Interativa

Aplicação simples para cálculo de massa corporal com validação de formulário e resultado explicado ao usuário.

HTML5CSS3JavaScript

Código demonstrativo

function calcularIMC(peso, altura) {
  if (!peso || !altura) {
    return "Preencha os campos";
  }

  const imc = peso / (altura * altura);
  return imc.toFixed(2);
}
