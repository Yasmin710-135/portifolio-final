Gerenciador de Tarefas (To-Do List)

Lista funcional para organizar tarefas e manter os itens salvos no LocalStorage do navegador.

HTML5CSS3JavaScript

Código demonstrativo

const tarefas = JSON.parse(
  localStorage.getItem("tarefas") || "[]"
);

function salvarTarefa(texto) {
  tarefas.push(texto);
  localStorage.setItem("tarefas", JSON.stringify(tarefas));
}
