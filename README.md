# Portfólio de Yasmin Melissa

Portfólio pessoal para apresentar projetos, habilidades e informações de contato em uma página web responsiva e moderna.

## Visão geral

Este projeto é uma landing page de portfólio desenvolvida com HTML, CSS e JavaScript, com foco em:

- apresentação pessoal e profissional;
- exibição de projetos em destaque;
- seção de habilidades e tecnologias;
- formulário de contato com validação básica;
- layout responsivo para desktop e mobile.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git/GitHub

## Como visualizar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/Yasmin710-135/portifolio.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd portifolio
   ```
3. Abra o arquivo `index.html` em um navegador, ou use uma extensão como Live Server no VS Code.

## Funcionalidades

- navegação por seções;
- menu responsivo;
- cards de projetos com links para páginas internas;
- lista de habilidades com visual organizado;
- formulário de contato com feedback visual.
